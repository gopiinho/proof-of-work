# Wallets

Wallets are essential software tools that are used by regular user to interact with Ethereum. You can think of it as a interface that makes the interaction easier. Tho it never holds any real funds or ether, since it stricly is all recorded on blockchain. What wallets really store is the users private keys.

Wallets are the primary link between users and Ethereum Dapps, primarly the interactions of sending transactions. The users always control their own tokens on network by signing with their keys from the wallet.
